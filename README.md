# Tor for Ubuntu Touch

> **Compatibility:** Made for Ubuntu Touch 24.04 and tested on UT 24.04-2.x.

A small transparent Tor proxy for Ubuntu Touch. It supports direct connections and four bridge types: vanilla (`plain`), `obfs4`, `webtunnel` and `snowflake`.

## What you need

Ubuntu Touch already comes with most of the tools:

- Python 3
- `iptables` and `ip6tables`
- `sudo`
- `dpkg-deb` (for unpacking downloaded binaries)
- `wget`

## Setup

Make the script executable, create a config and download the binaries:

```sh
chmod +x tor-ubuntu-touch
./tor-ubuntu-touch --init-config
./tor-ubuntu-touch --download-binaries
```

Downloaded binaries go into `.bin/`. The downloader verifies package SHA256 hashes and extracts the executables without installing anything into Ubuntu Touch.

The preferred `lyrebird` binary handles `obfs4`, Snowflake and WebTunnel. Vanilla bridges don't need an extra transport binary.

## Configuration

All settings are configured in `config.json`. You can start with `config.example.json`.

Each bridge type has its own array, so you can add as many bridges as you need:

```json
{
  "tor": {
    "trans_port": 9040,
    "dns_port": 5353,
    "socks_port": 9050,
    "bootstrap_timeout": 240,
    "tor_user": "auto"
  },
  "bridges": {
    "plain": [],
    "obfs4": [],
    "webtunnel": [],
    "snowflake": []
  },
  "firewall": {
    "allow_lan": true
  }
}
```

Put each full bridge line into the matching array as a separate JSON string. Don't include the `Bridge` keyword.

Bridge line formats:

- `plain`: `HOST:PORT [FINGERPRINT]`
- `obfs4`: `obfs4 IP:PORT FINGERPRINT cert=... iat-mode=0`
- `webtunnel`: `webtunnel IP:PORT FINGERPRINT url=https://... ver=0.0.2`
- `snowflake`: `snowflake IP:PORT FINGERPRINT ...`

IPv4, bracketed IPv6 and, for vanilla bridges, hostnames are supported. Keep all transport-specific parameters intact, especially Snowflake's `url`, `front`/`fronts` and `ice` values.

## Starting Tor

No bridges:

```sh
sudo ./tor-ubuntu-touch --start
```

Choose the bridge types you have configured:

```sh
sudo ./tor-ubuntu-touch --start --use-bridges obfs4
sudo ./tor-ubuntu-touch --start --use-bridges webtunnel
sudo ./tor-ubuntu-touch --start --use-bridges snowflake
sudo ./tor-ubuntu-touch --start --use-bridges plain
```

You can combine multiple types or use all configured bridges:

```sh
sudo ./tor-ubuntu-touch --start --use-bridges obfs4 snowflake
sudo ./tor-ubuntu-touch --start --use-bridges all
```

A selected type must have at least one bridge configured.

## If you use Nix on UT (like me)

Add `tor` and `obfs4` to `home.packages` in your `home.nix`:

```nix
home.packages = with pkgs; [
  tor
  obfs4
];
```

Apply the changes:

```sh
home-manager switch
```

Then use `--nix-binaries` when starting the proxy:

```sh
sudo ./tor-ubuntu-touch --start --nix-binaries
sudo ./tor-ubuntu-touch --start --use-bridges obfs4 --nix-binaries
sudo ./tor-ubuntu-touch --start --use-bridges snowflake webtunnel --nix-binaries
```

## Stop and check

```sh
sudo ./tor-ubuntu-touch --status
sudo ./tor-ubuntu-touch --logs
sudo ./tor-ubuntu-touch --logs --follow
sudo ./tor-ubuntu-touch --stop
```

## File locations

- `config.json` and `.bin/` stay in this directory.
- Logs and saved state go to `~/.local/state/tor-ubuntu-touch/` and `~/.local/share/tor-ubuntu-touch/`.
- Temporary files go to `/run/tor-ubuntu-touch-UID/` and `/home/.tor-ubuntu-touch-UID/`.

The tool does not modify the Ubuntu Touch read-only system image or install system packages. Its own runtime files are kept separate from system files.

## A few things to know

- The proxy handles traffic generated by the phone, not tethered clients.
- Tor carries TCP, not ICMP or arbitrary UDP. `ping` and most UDP-only apps won't work.
- QUIC is blocked, so Morph Browser should fall back to TCP.
- External IPv6 and direct DNS are blocked to prevent leaks.
- Local LAN access is allowed by default. Set `firewall.allow_lan` to `false` to disable it.
